## 🚀 About

**CDA Downloader GUI** is a small Python desktop frontend that launches the `cda-dl` command for a supplied CDA page URL. The download process runs in a background thread so the graphical interface can remain responsive.

It is designed for users searching for a **CDA downloader GUI**, **cda-dl frontend**, **Python video downloader GUI** or a simple Tkinter wrapper around the `cda-dl` command.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🔗 URL input | Paste a supported CDA page address |
| ▶️ One-click start | Launch the configured download workflow |
| 🧵 Background thread | Keeps the window responsive during processing |
| ✅ Status messages | Basic success and error feedback |
| 🐍 Python source | `cda.py` included |
| 🪟 Windows build | Repository also includes a Windows executable build |

---

## 📋 Requirements

- Python 3.x
- `cda-dl` available as a system command

Run the Python version:

```bash
git clone https://github.com/Swir/cda-pl.git
cd cda-pl
python cda.py
```
