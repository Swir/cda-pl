## 🇵🇱 Polski

`cda-pl` to prosty program z interfejsem graficznym do uruchamiania narzędzia `cda-dl` dla podanego adresu strony CDA. Aplikacja działa w osobnym wątku, dzięki czemu okno pozostaje responsywne podczas pobierania.

### Funkcje

- pole do wklejenia adresu,
- przycisk uruchamiający pobieranie,
- obsługa błędów i komunikat po zakończeniu,
- wersja źródłowa `cda.py`,
- gotowy plik `cda.exe` dla Windows.

### Uruchomienie

Wymagany jest Python 3 oraz dostępne w systemie polecenie `cda-dl`.

```bash
python cda.py
```

### Ważne

Korzystaj wyłącznie z materiałów, które możesz legalnie pobierać i zapisywać. Projekt nie służy do omijania płatnych zabezpieczeń ani ograniczeń dostępu.

## 🇬🇧 English

`cda-pl` is a small graphical frontend that launches the `cda-dl` command for a supplied CDA page URL. Downloads run in a background thread so the window can remain responsive.

### Features

- URL input field,
- one-click download start,
- basic error and completion messages,
- `cda.py` source version,
- bundled `cda.exe` Windows build.

### Run

Python 3 and the `cda-dl` command must be available on the system.

```bash
python cda.py
```

### Legal use

Use the application only for content you are permitted to download and store. The project is not intended to bypass paid access controls or other restrictions.
